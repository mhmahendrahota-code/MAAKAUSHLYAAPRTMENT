# 🏢 माँ कौशल्या अपार्टमेंट (Maa Kaushalya Apartment RWA) पोर्टल

डिजिटल प्रबंधन और सुरक्षा पोर्टल — रेसिडेंट वेलफेयर एसोसिएशन (RWA), माँ कौशल्या अपार्टमेंट, रायपुर (छत्तीसगढ़)।

यह एक प्रीमियम, आधुनिक और बहु-भूमिका (Multi-role) आधारित वेब एप्लीकेशन है जो माँ कौशल्या अपार्टमेंट के निवासियों, सुरक्षा विंग और आरडब्ल्यूए प्रशासनिक समिति के दैनिक संचालन को सुव्यवस्थित, सुरक्षित और डिजिटल बनाता है।

---

## 🌟 मुख्य विशेषताएं (Core Features)

### 1. निवासी पोर्टल (Resident Portal)
* **रखरखाव बिलिंग (Maintenance Bills):** मासिक रखरखाव शुल्कों की समीक्षा और भुगतान विवरण की ट्रैकिंग।
* **शिकायत निवारण (Complaints):** रखरखाव, पार्किंग या सुरक्षा संबंधी शिकायतों का ऑनलाइन पंजीकरण और निवारण स्थिति ट्रैकिंग।
* **सूचना पट्ट (Notices):** आरडब्ल्यूए द्वारा जारी महत्वपूर्ण घोषणाओं और आपातकालीन सूचनाओं का डिजिटल प्रसारण।
* **दस्तावेज़ डाउनलोड (Downloads & Printable Forms):** सोसायटी नियमों की फाइल्स और इंटरैक्टिव फॉर्म्स तक त्वरित पहुंच।

### 2. सुरक्षा गार्ड डेस्क (Security Gateway Log)
* **आगंतुक प्रबंधन (Visitor Entry System):** सोसायटी गेट पर आने वाले मेहमानों, डिलीवरी एजेंट्स और दैनिक सेवा प्रदाताओं (maids, drivers) का डिजिटल प्रविष्टि रजिस्टर।
* **आपातकालीन गेट-पास (Secure Transit):** वाहनों के प्रवेश और गेट-पास का त्वरित सत्यापन।

### 3. आरडब्ल्यूए प्रशासनिक नियंत्रण (RWA Admin Center)
* **निवासी निर्देशिका (Member Directory):** निवासियों, फ्लैटों, वाहन स्टिकर्स और परिवार आकारों का विस्तृत डेटाबेस प्रबंधन।
* **वित्तीय लेखा-जोखा (Treasury & Audits):** मासिक आय, व्यय विवरण और एकत्रित भंडार का लेखा-परीक्षण (financial audits) प्रकाशन।
* **घोषणा प्रबंधन:** नए सूचना-पत्रों और उप-नियमों (rules & bye-laws) को वेबसाइट पर लाइव करना।

## 📄 सार्वभौमिक निवासी पंजीकरण प्रपत्र (Universal Form) 🆕
हाल ही में **Downloads** सेक्शन में एक नया **Universal Resident Details Form** एकीकृत किया गया है। यह प्रपत्र ऑनलाइन 'Join Portal' के सभी डेटा क्षेत्रों को समाहित करता है और भौतिक (Hard-copy) विवरण संग्रह के लिए तैयार किया गया है:
* **विस्तृत डेटा कैप्चर:** बुनियादी विवरण, कब्ज़ा विवरण (फ्लैट स्वामी/किरायेदार), किरायेदार के लिए फ्लैट ओनर विवरण, गतिशील पारिवारिक तालिका, वाहन नंबर रजिस्टर, पालतू पशु, आपातकालीन संपर्क और निवासी फोटो।
* **लचीले प्रिंट मोड:** 
  1. **खाली प्रपत्र (Blank A4 Form):** बिना विवरण भरे सीधे एक साफ फॉर्मेट प्रिंट करें, जिसमें हाथ से लिखने के लिए खाली लाइन्स (`......`) और ग्रिड्स बनी हों।
  2. **भरा हुआ प्रपत्र (Pre-filled Form):** डिजिटल रूप से विवरण भरकर "विवरण भरकर प्रिंट करें" दबाएं, जो सीधे भरे हुए विवरणों के साथ A4 पत्रक का प्रिंट डायलॉग खोलता है।
  3. **डेटा बैकअप (.txt):** निवासी प्रोफाइल का डेटा `.txt` प्रारूप में डाउनलोड करने की सुविधा।
* **प्रीमियम A4 प्रारूप:** माँ कौशल्या अपार्टमेंट के लेटरहेड, फोटो फ्रेम, नियम-कानूनों की घोषणा और आरडब्ल्यूए अध्यक्ष व निवासी के हस्ताक्षर ब्लॉकों से सुसज्जित।

## 🛠️ तकनीकी ढांचा (Tech Stack)

### फ्रंटएंड (Frontend)
* **कोर:** HTML5, React.js (Vite द्वारा संचालित)
* **डिजाइन व स्टाइलिंग:** TailwindCSS, Vanilla CSS, Lucide React (आइकॉन्स)
* **स्टेट मैनेजमेंट:** React Context (Authentication)

### बैकएंड (Backend)
* **कोर:** Node.js, Express.js
* **डेटा ट्रांसफर:** JSON API architecture with Proxy setups

## 🚀 स्थानीय रूप से सेटअप और रन करने की विधि (Installation & Setup)

पोर्टल को अपने कंप्यूटर पर रन करने के लिए नीचे दिए गए चरणों का पालन करें:

### पूर्वापेक्षाएँ (Prerequisites)
* आपके कंप्यूटर पर **Node.js** (v16 या अधिक) स्थापित होना अनिवार्य है।

### 1. प्रोजेक्ट क्लोन करें (Clone & Prepare)
प्रोजेक्ट फ़ोल्डर में जाएं:
```bash
cd "d:\MAKAUSHLYA APARTMENT"
```

### 2. बैकएंड सर्वर शुरू करें (Backend Server Setup)
```bash
cd server
npm install
npm run dev
```
बैकएंड एपीआई डिफ़ॉल्ट रूप से **[http://localhost:5000](http://localhost:5000)** पर चलेगा।

### 3. फ्रंटएंड क्लाइंट शुरू करें (Frontend Client Setup)
एक नई टर्मिनल विंडो खोलें और चलाएं:
```bash
cd client
npm install
npm run dev
```
फ्रंटएंड पोर्टल डिफ़ॉल्ट रूप से **[http://localhost:3000](http://localhost:3000)** पर होस्ट होगा।
